# コントローラーのプロファイル

PCに接続したコントローラーの入力を、Switchのボタン・十字キー(Hat)・スティックに割り当てる設定です。
このフォルダに `.json` ファイルを置くと、コントローラーの名前と各プロファイルの `match` を比べて自動で使われます。

- 使うコントローラーは、Manual Control タブの Hardware の「Device」で選びます。
  - 接続中のコントローラーが「番号: 名前」で表示されます(番号は接続順)。同じ種類のコントローラーは番号で区別します。
  - `Auto` は、いずれかのプロファイルに名前が一致する、番号が最も小さいコントローラーを使います。
  - 一覧はコンボボックスを開くたびに更新されます。
- どのプロファイルにも一致しない場合は、Switch Proコントローラー用のプロファイルを使います。
  そのコントローラーの名前の一部を、使いたいプロファイルの `match` に追加してください。
- Switch Proコントローラー用のプロファイル(`Switch Pro Controller`)は組み込みです。
  同じ `name` のJSONファイルを置くと、そちらが優先されます。
- ファイルの追加・修正は、次に「Use Pro Controller」を有効にしたときに読み込まれます。

## GUIで作る

Manual Control タブの Hardware の「Device」でコントローラーを選び、隣の「Add Profile」ボタンを押すと設定画面が開きます。

1. 開いてすぐは、コントローラーに触れずに待ちます(静止時の状態を記録します)。
2. 表示されたSwitchのボタン・十字キー・スティックに割り当てたい入力を、1つずつ押します。
   - 十字キーでコントローラーのHatを押した場合は、4方向まとめて割り当てます。
   - スティックは、表示された方向(右・下)に倒します。
   - 「スキップ」は今の割り当てのまま次へ、「割り当てなし」はその入力を使わない設定にします。
3. 最後に一覧を確認して「保存」します。

- 保存先は、名前が一致する既存の設定ファイルがあればそのファイル、なければコントローラー名から作ったファイルです。
- 既存の設定ファイルがある場合は、開始前に知らせ、保存時に更新するか確認します。
- 画面の「入力中」には、静止時から変化している入力が表示されます。何も触れていないのに表示される場合は、スティックのずれ(ドリフト)などで誤って割り当てられることがあります。「戻る」でやり直してください。

## ボタン番号の調べ方

`SerialController` フォルダで次を実行し、ボタンやスティックを動かすと番号が表示されます。

```
python -m Commands.ControllerProfile --probe
```

## 書式

```json
{
  "name": "Xbox Controller",
  "match": ["Xbox", "XInput"],
  "buttons": {
    "B": 0,
    "A": 1,
    "ZL": {"axis": 4, "threshold": 0.0},
    "ZR": {"axis": 5, "threshold": 0.0}
  },
  "hat": {"type": "hat", "index": 0},
  "sticks": {"lx": 0, "ly": 1, "rx": 2, "ry": {"axis": 3, "invert": false}},
  "deadzone": 0.35
}
```

| 項目 | 内容 |
|---|---|
| `name` | プロファイルの名前(開始時の表示に使います) |
| `match` | コントローラー名に含まれる文字列のリスト(大文字・小文字は区別しない)。複数のプロファイルに一致する場合は `name` の名前順で先のものを使います |
| `buttons` | Switchのボタン名と、コントローラーの入力の対応。書かなかったボタンは使いません |
| `hat` | 十字キーの取り方(下記) |
| `sticks` | `lx` `ly` `rx` `ry` に使う軸の番号。`{"axis": 番号, "invert": true}` で向きを反転します |
| `deadzone` | スティックの中心付近を無視する範囲(0以上1未満。初期値 0.35) |

### buttons に書けるボタン名

`A` `B` `X` `Y` `L` `R` `ZL` `ZR` `MINUS` `PLUS` `LCLICK` `RCLICK` `HOME` `CAPTURE`

値は次のどれかです。

- `3` : ボタン番号
- `{"axis": 4, "threshold": 0.0}` : 軸の値が `threshold` を超えたら押したとみなす(トリガーなど)
- `{"axis": 4, "threshold": 0.5, "direction": -1}` : 軸を負の方向に倒したら押したとみなす

### hat

- `{"type": "hat", "index": 0}` : コントローラーのHatをそのまま使う
- `{"type": "buttons", "up": 11, "down": 12, "left": 13, "right": 14}` : 上下左右がボタンの場合。
  値には `buttons` と同じく軸の指定も書けます

## 注意

- ボタンの割り当ては、Switchのボタンの**位置**に合わせるのがおすすめです。
  例えば Xbox コントローラーは A/B と X/Y の位置が Switch と逆なので、`Xbox_Controller.json` では下のボタン(Xbox の A = 番号0)を Switch の B にしています。
- 番号はOSや接続方法(USB/Bluetooth)で変わることがあります。うまく動かないときは `--probe` で確認してください。
