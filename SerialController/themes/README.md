# テーマの追加

このフォルダーに、配色を書いたファイル(`*.json`)を置くと、メニューの 表示 > テーマ に足されます。

## 作り方(画面で色を選ぶ)

1. メニューの 表示 > テーマ > 「テーマを作る / 編集する...」を選びます。今の配色の色が入った画面が開きます。
2. 色の見本(四角)を押して色を選ぶか、右の欄に `#rrggbb` の形で打ち込みます。
   「選んでいる色を、本体の画面で試す」にチェックが入っている間は、選んだ色が本体の画面に、一時的に反映されます。
3. 名前を付けて「保存」を押すと、このフォルダーに `my_theme.json`(2 つ目からは `my_theme_2.json`、…)ができて、そのテーマに切り替わります。
   保存せずに閉じると、元のテーマに戻ります。
4. 作ったテーマを直すときは、同じ画面の「編集するテーマ」で選びます。「削除」で、ファイルごと消せます。

## 作り方(ファイルを書く)

ほかの人が作ったファイルをこのフォルダーに置く場合や、エディタで直接書く場合:

1. このフォルダーに、下の「ファイルの形」のファイル(`*.json`)を置きます。
2. `"name"`(メニューに出る名前)と、`"colors"` の色を書き換えて保存します。
3. 表示 > テーマ > 「テーマを読み込み直す」を選びます。メニューに名前が出るので、選びます。
   使っている途中のテーマのファイルを書き換えた場合も、「テーマを読み込み直す」で色が変わります。

ファイルの名前(`.json` の前)は、設定に覚えるための名前として使います。
名前を変えると、そのテーマを選んでいたプロファイルは、次の起動時にデフォルトのテーマに戻ります。

## ファイルの形

```json
{
  "name": "My Theme",
  "dark": false,
  "colors": {
    "bg": "#f3f3f3",
    "surface": "#fafafa",
    "field": "#ffffff",
    "border": "#d1d1d1",
    "fg": "#1b1b1b",
    "muted": "#6e6e6e",
    "accent": "#0067c0",
    "select": "#cce4f7",
    "select_fg": "#1b1b1b",
    "check_fg": "#ffffff",
    "button": "#fdfdfd",
    "button_active": "#ececec",
    "sash": "#e0e0e0",
    "link": "#0066cc",
    "code": "#eef0f2",
    "danger": "#c42b1c"
  }
}
```

- `"name"`: メニューに出す名前(40 文字まで)。
- `"dark"`: 暗い配色なら `true`、明るい配色なら `false`。タイトルバーの色などに使います。書かなければ、背景の色の明るさから決めます。
- `"colors"`: 役割ごとの色。`"#rrggbb"` の形で書きます。下の 16 個は、すべて必要です。

| 役割 | 使う所 |
|---|---|
| `bg` | ウィンドウの背景 |
| `surface` | 少し浮いた部分(タブの見出し、メニューバー) |
| `field` | 入力欄、出力画面(Output)の背景 |
| `border` | 枠線 |
| `fg` | 文字 |
| `muted` | 薄い文字(使えない項目、選んでいないタブ、Log タブの DEBUG) |
| `accent` | 強調(チェック、フォーカス) |
| `select` | 選んでいる所の背景 |
| `select_fg` | 選んでいる所の文字 |
| `check_fg` | チェックの印 |
| `button` | ボタン |
| `button_active` | マウスを重ねたボタン |
| `sash` | 仕切り線 |
| `link` | リンクの文字 |
| `code` | Instruction Manual のコードの背景 |
| `danger` | 赤(記録中の表示、Log タブの ERROR) |

次の 6 個は、書かなければ、ほかの役割の色から決めます。

| 役割 | 使う所 | 書かないとき |
|---|---|---|
| `text_fg` | 入力欄・出力画面の文字 | `fg` |
| `menu` | メニューの背景 | `surface` |
| `menu_fg` | メニューの文字 | `fg` |
| `tile_border` | コントローラー設定のプリセットの枠 | `border` |
| `strong_border` | 選んでいるプリセットの枠 | `fg` |
| `focus_border` | 入力中の一覧などの枠 | `border` |

## うまく読み込めないとき

読み込めないファイルは、メニューに足されません。「テーマを読み込み直す」を選ぶと、理由を Output に表示します
(起動時は、Log タブと log フォルダーのファイルに残ります)。よくある原因:

- `,` や `"` の書き忘れ(JSON として読めません)
- 16 個の役割のどれかがない、役割の名前の書き間違い
- 色が `"#rrggbb"` の形でない(`"red"` や `"#fff"` は使えません)
