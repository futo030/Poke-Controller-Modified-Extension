# はじめに
- Poke-Controller Monitor は、複数起動した Poke-Controller Modified Extension のウィンドウを、1 つの画面でまとめて見るための補助ツールです。
- ウィンドウごとに、実行中のコマンド・Output・カメラの映像を表示します。再生・一時停止・停止と、そのウィンドウを最前面に表示する操作ができます。
- 見られるのは、同じ PC で、--monitor を付けて起動したウィンドウです。最大 12 個まで並べられます。
- Web 版(--ui web)も、--monitor を付けて起動すると見られます。▶ で始まるのは、操作できるブラウザが一覧で選んでいるコマンドです。Web 版の画面は、前面に表示できません。
- コマンドを選び直すことは、できません。コマンドは、それぞれのウィンドウで選んでおきます。

# 起動する

## 見たいウィンドウを起動する
- Poke-Controller を、--monitor を付けて起動します。PokeConExtension.bat --monitor(または ExecutePokeConModified-Extension_with_monitor.bat)を使うか、SerialController フォルダで次を実行します。
```
python Window.py --profile プロファイル名 --monitor
```
- プロファイルごとの bat を使っている場合は、bat の中の起動の行(python Window.py、または PokeConExtension.bat の行)の最後に --monitor を足します。
- --monitor を付けていないウィンドウは、見られません(「起動していません」と表示します)。
- 同じプロファイルを 2 つ起動した場合、2 つ目(設定を保存しないウィンドウ)は見られません。

## Monitor を起動する
- PokeConExtension_Monitor.bat(または ExecutePokeConMonitor.bat)を使うか、SerialController フォルダで次を実行します。
```
python Monitor.py
```
- 初めて起動したときに、いくつのウィンドウを見るか(1〜12)を選びます。次からは、前回の数で開きます。
- 起動時に数を指定することもできます。
```
python Monitor.py --count 6
```
- Monitor と、見たいウィンドウは、どちらを先に起動しても構いません。後から起動したウィンドウにも、自動でつながります。

# 画面の見かた

## 上の欄
- 数: 並べる枠の数(1〜12)です。変えると、枠を並べ直します。
- 映像 (fps): 映像を更新する回数の上限(毎秒 2〜30)です。カメラの映像がそれより少ない場合は、カメラに合わせます。
- All Start / All Stop: つながっているすべてのウィンドウで、コマンドを開始 / 停止します(下の「操作する」を参照)。

## メニュー
- ファイル > 終了: Monitor を閉じます。
- 表示 > テーマ: Monitor 全体の配色を選びます。
- ヘルプ > Instruction Manual / LICENSE: この説明と、Monitor のライセンスを表示します。

## 枠
- 上の欄で、その枠に表示するプロファイルを選びます。「(未選択)」にすると、何も表示しません。
- 右上に、状態(待機 / 実行中 / 一時停止 / 停止中)を表示します。
- その左の欄で、その枠に表示する出力画面を選びます。Stdout は、そのウィンドウの print の出力先(Others タブの Stdout)です。#1 / #2 で、Output#1 / Output#2 に固定できます。
- その下に、実行中のコマンドの名前を表示します。待機中は、そのウィンドウの一覧で選んでいるコマンドを「(選択中: 名前)」と表示します。
- 映像: そのウィンドウのカメラの映像です。カメラを開いていないときは「映像がありません」と表示します。
- Output: そのウィンドウの出力画面の、最後の数行です。
- つながっている枠は、そのウィンドウのテーマの配色で表示します。ウィンドウを見分ける目印になります。

## 下の行
- 左に、最後に行った操作などの知らせを表示します。
- 右に、つながっているウィンドウの数を「起動中 n / 枠の数」と表示します。

# 操作する

## コマンドの操作
- ▶(再生): 待機中は、そのウィンドウの一覧で選んでいるコマンドを開始します。一時停止中は、再開します。
- ⏸(一時停止): 実行中のコマンドを一時停止します。Mcu コマンドなど、一時停止できないコマンドでは押せません。
- ■(停止): 実行中・一時停止中のコマンドを停止します。
- ボタンは、そのウィンドウの Start / Pause / Stop を押すのと同じ動きです。そのウィンドウで Start を押せないとき(Shortcut・History のタブを開いているとき、操作の記録中など)は、▶ も押せないか、押しても始まりません。

## まとめて開始・停止する
- All Start: つながっているすべてのウィンドウで、▶ を押したのと同じ操作を行います。待機中のウィンドウは、選んでいるコマンドを開始し、一時停止中のウィンドウは、再開します。実行中のウィンドウと、▶ を押せないウィンドウは、そのままです。
- All Stop: つながっているすべてのウィンドウで、実行中・一時停止中のコマンドを停止します。
- 対象は、枠に表示していて、つながっているウィンドウです。枠に出していないウィンドウには、何もしません。
- 押すと、対象のウィンドウとコマンドの一覧を表示して、確認します。「はい」を選ぶと実行し、下の行に、頼んだウィンドウの数を表示します。対象がないときは、確認を出さずに、その旨を下の行に表示します。

## ウィンドウを前面に表示する
- 前面に表示: そのウィンドウを、最前面に表示します。最小化している場合は、元に戻します。
- コマンドを選び直したい、設定を変えたい、というときに使います。

## 大きく表示する
- 映像をダブルクリックすると、その 1 つを別のウィンドウで大きく表示します。Output も、長く表示します。表示する出力画面は、開いた元の枠と同じです(大きく表示した中でも、切り替えられます)。
- ほかの枠の映像をダブルクリックすると、大きく表示する対象が切り替わります。

## 枠の大きさ
- Monitor のウィンドウの大きさを変えると、枠と映像も伸び縮みします。映像は、縦横の比を保ちます。

# 覚えている設定
- 次の内容は、次に開くときも同じです。
- 枠の数
- どの枠に、どのプロファイルを表示するか、どの出力画面を表示するか(12 個分。数を減らしてから戻しても、元の割り当てに戻ります)
- 映像 (fps)、テーマ
- ウィンドウの大きさと位置
- 設定は、SerialController/profiles/monitor_tool.json に保存します。初めの状態に戻したいときは、Monitor を閉じてから、このファイルを消します。

# 負荷について
- --monitor を付けても、コマンドの動き(送るデータ、待ち時間、画像認識の結果)は変わりません。
- 映像を表示している間、見られている側のウィンドウは、映像を縮めて送る処理を行います。映像 (fps) を大きくするほど、また、枠を大きくするほど、PC の負荷が上がります。
- 多くのウィンドウを同時に見るときは、映像 (fps) を小さめ(5 前後)にすることをおすすめします。
- 映像は、カメラの画像をそのまま表示します。プレビューの Mask や、明るさの調整は掛かりません。

# 困ったとき

## 「起動していません」と表示される
- そのプロファイルのウィンドウを、--monitor を付けて起動しているか確認します。
- 同じプロファイルの 2 つ目のウィンドウ(「設定を保存しません」と表示されるもの)は、見られません。
- 起動した直後は、つながるまで 1 秒ほど掛かることがあります。

## 「映像がありません」と表示される
- そのウィンドウで、カメラを開いているか確認します(Camera タブの Reload Camera)。

## ▶ を押しても始まらない
- そのウィンドウで、Python Command または Mcu Command のタブを開き、コマンドを選んでいるか確認します。
- 前面に表示 を押して、そのウィンドウの様子を確認します。

## 前面に表示 を押しても、手前に出てこない
- Windows の設定や、ほかのアプリの状態によっては、タスクバーのボタンが光るだけになることがあります。その場合は、タスクバーから選びます。

## 動きが重い
- 映像 (fps) を小さくします。枠の数を減らすか、Monitor のウィンドウを小さくするのも有効です。
