# Web ブラウザ版の紹介

Poke-Controller の画面を、Web ブラウザで表示できるようになりました。機能を、次のページから紹介します。
- 「次へ >」「< 前へ」でページを送ります。

【重要】このツール専用の環境(uv と .venv)へ移行します。ver.0.3.x 以降は、完全に uv に移行します(以前からの Python と pip の環境では、起動できなくなります)。
- uv とは: Python 本体と、Python のライブラリを、まとめて用意して管理する道具です(Astral 社が公開している、無料のオープンソースのソフトウェア)。これまで自分で行っていた「Python のインストール」と「pip でのライブラリのインストール」を、uv が代わりに行います。
- 目的: Python と必要なライブラリの版を、全員で同じにそろえ、Python のバージョンを上げやすくするためです(今回、Python 3.13 になります)。PC に Python を入れていなくても、使えるようになります。
- 移行: 以前からの方法で起動すると、移行するかを確認する画面が出ます。「はい」を選ぶと、uv という道具が、ツールのフォルダの中に専用の環境(.venv)を作ります。今の Python と、そこに入っているライブラリは、そのまま残ります。
- 足していたライブラリ: 自作のスクリプト用に足していたライブラリは、移行のときに、一覧から選んで引き継げます。
- ライブラリの追加: 移行した後は、pip install では入りません。PokeConExtension_AddLibrary.bat を実行して、ライブラリの名前を入力します。
- 起動: Web ブラウザ版は、PokeConExtension.bat --ui web で起動します。今までの bat でも起動できます(移行した後は、どちらも専用の環境で動きます)。
- ver.0.2.x の間は、以前からの環境でも起動できます。早めの移行をおすすめします。
- 詳しくは、ヘルプ > Instruction Manual の「起動と終了」にある「環境(uv と .venv)」を見てください。
- この画面は、右上の ヘルプ > 機能紹介 からいつでも開けます。
- 「今後は表示しない」にチェックを入れて OK を押すと、起動時には表示されなくなります。紹介の内容が更新されたときは、もう一度表示されます。
- 使い方の説明は、ヘルプ > Instruction Manual にあります。

# 起動のしかた

SerialController フォルダで、--ui web を付けて起動します。
- python Window.py --ui web
- 付けない場合は、これまでのウィンドウの画面(tkinter 版)で起動します。
- PokeConExtension.bat --ui web でも起動できます。専用の環境(.venv)には、Web 版に必要なパッケージが初めから入っています。
- 以前からの環境(PC の Python と pip)で使うときだけ、追加のパッケージを入れます(pip install -r requirements-web.txt)。
- プロファイルは --profile で指定します。付けない場合は default を使います。
- ポート番号は 8765 から順に、空いている番号を使います。複数のプロファイルを同時に起動できます。
- 画面を開けるのは、このツールを動かしている PC のブラウザだけです。

# 通知

コマンドの開始時・終了時に、Windows / LINE / Discord へ通知できます(設定 の Notification)。
- Discord の開始時・終了時の通知には、文字に、キャプチャ画面の今の画像が付きます。
- Discord の通知先の設定の手順は、ヘルプ > Instruction Manual の「Discord 通知の設定」にあります。
- tkinter 版では、通知に付ける画像を、ウィンドウ全体にすることもできます。Web 版では、いつも、キャプチャ画面の画像を送ります。

# tkinter 版との関係

設定は共通で、画面の配置は別です。
- カメラ・シリアル・キーの対応・ショートカット・履歴などの設定は、プロファイルに保存され、どちらの画面でも同じものを使います。
- 画面の配置(パネルの位置、テーマ、境目の線の位置など)は、Web 版ではブラウザに保存します。
- スクリプト(コマンド)は、どちらの画面でも同じものを使えます。
- スクリプトが tkinter を直接使って独自のウィンドウを開く場合は、Web 版では動きません。

# 画面の構成

左にプレビューと操作の部品、右にコマンドの一覧と Output が並びます。
- 見出しに、プロファイル・シリアル・カメラの状態が表示されます。
- 右上のボタンは、設定 / 表示 / ヘルプ / 終了 です。
- 左の列と右の列の間の線をドラッグすると、プレビューの大きさが変わります。
- Output#1 と Output#2 の間の線をドラッグすると、高さの比率が変わります。
- 右側のパネルを下に置いたときは、プレビューの横の線と、下の段の左右の間の線で、幅を変えられます。
- どちらの線も、ダブルクリックで元に戻ります。

# 表示メニュー

画面の見た目と配置を切り替えます。
- テーマ: 自動(OS の設定) / ライト / ダーク
- プレビューの大きさ: 列の幅に合わせる、または決まった幅(480~1920)
- プレビューの画質: ブラウザへ送る映像の大きさ。大きいほどくっきりしますが、PC の負荷が増えます
- 右側のパネルの位置: 右 / 下
- コマンドの一覧と Software-Controller の位置の入れ替え
- 表示する部品: コマンドの一覧 / Output / Software-Controller / 手動操作
- ミニ画面: プレビューと Start だけの画面
- 画面のリセット: 配置を初めの状態に戻す

# 設定

右上の「設定」で、設定が画面の右側に開きます。
- 開いたまま、プレビューを見たり操作したりできます。
- 変更はその場で反映され、プロファイルに保存されます。
- いちばん上の Status に、今つながっている機器(カメラ、音声、シリアル)と、実行中のコマンド(開始した時刻)が表示されます。
- Camera / Serial / Audio / Notification / Mask / Touch Screen / Controller Color / Key Config / Controller / Others / Discord / LINE / Profile があります。
- Camera の Device や Capture Size を変えると、その場でカメラを開き直します。

# コマンド

コマンドの一覧には、Python / Mcu / History / Shortcut のタブがあります。
- 名前での検索、タグでの絞り込み(複数選択)、名前・更新日時・使用頻度での並び替えができます。
- 行をダブルクリックすると実行します。F6 で実行、Esc で停止、F5 で読み込み直しです。
- 右クリックで、ファイルを開く・パスのコピー・Shortcut への設定ができます。
- History の Last Run のボタンで、新しい順と古い順を切り替えます。
- ブラウザのタブを閉じても、実行中のコマンドは止まりません。開き直すと、続きの出力が表示されます。

# プレビュー上の操作

プレビューの上で、マウスを使った操作ができます。
- Ctrl + 左クリック: その位置の座標と色を Output に表示
- Ctrl + Shift + 左ドラッグ: 選んだ範囲を Captures フォルダに保存
- Ctrl + Alt + 左ドラッグ: 選んだ範囲を、名前を付けて Template フォルダに保存
- 「左ドラッグ: Lスティック」「右ドラッグ: Rスティック」にチェックを入れると、ドラッグでスティックを操作
- Format が Qingpi / 3DS Controller のときは、右ドラッグがタッチスクリーンになります

# 手動操作

キーボード・コントローラー・画面上のコントローラーで操作できます。
- キーボード: ツールを動かしている PC 側でキーを読み取ります。操作できる画面が前面にあり、入力欄を選んでいない間だけ受け付けます。
- コントローラー: 設定 > Controller で Device を選びます。ボタンの割り当ても、同じ場所で設定できます。
- Software-Controller: 左クリックで押す、右クリックで押しっぱなしに固定します。HOLD でも固定できます。
- 表示 > Controller Simulator で、大きいコントローラーを開けます。
- Record で、手動操作を記録してスクリプトとして出力できます。
- 「すべての入力を離す」で、押したまま・倒したままになっている入力を、すべて離せます。

# ツール

見出しの「ツール」から、次の画面を開けます(操作できる画面だけ)。
- タグを編集: コマンドのファイルを開かずに、タグを足したり外したりします。
- 新しい自動化スクリプトをつくる: 新しいスクリプトのひな形を作ります。
- Keyboard: Switch のキーボード画面に、画面上のキーボードから文字を打ちます。
- モニター: --monitor を付けて起動した、ほかのウィンドウの状態・Output・映像を、まとめて表示します。
- --ui web に --monitor を付けて起動すると、補助ツール(Monitor.py)からも、この画面を見られます。

# Output のタブと検索

Output に、Page 1~3 のほかのタブと、文字の検索があります。
- Serial: 機器へ送ったデータを、[時刻][Data の Format の名前] 値 の形で表示します(Show Serial のチェックに関係なく、いつも表示します)。
- Log: ログを、レベルごとに色を付けて表示します。Level で、表示するレベルを絞り込めます。
- Note: 自由に書き込めるメモです。プロファイルごとに、自動で保存します(ウィンドウの画面と同じ内容です)。
- 文字の検索: 出力画面をクリックしてから Ctrl+F を押すか、タブの右端の 🔍 を押します。「Aa」で、大文字と小文字の区別を切り替えます。

# Mask とタッチスクリーンの範囲

プレビューをドラッグして、範囲を指定できます。
- Mask(目隠し)は、SNSにおける投稿や配信を想定した、見せたくない情報を隠すための機能です。
- 設定 > Mask の「追加(プレビューをドラッグ)」を押してから、プレビュー上をドラッグすると、目隠しを追加します。
- 設定 > Touch Screen の「プレビューをドラッグして指定」で、タッチスクリーンの範囲を指定します。
- どちらも、数値で細かく直せます。座標は、取り込みサイズ(Capture Size)の上の値です。

# 複数の画面から開いたとき

操作できるのは、最初に開いた1つだけです。
- ほかのタブやブラウザから開くと「閲覧のみ」と表示され、映像と出力を見ることだけができます。
- 操作していた画面を閉じると、次の画面が操作できるようになります。
- 終了は、右上の「終了」ボタン、またはコンソールでの Ctrl+C で行います。
